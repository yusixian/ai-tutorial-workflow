# 读音修正

字幕保持正确写法，配音单独处理念法。下面的文本和编号均为通用示例，不取自原视频。

## 四层念法

| 层 | 位置 | 用途 | 示例 |
| --- | --- | --- | --- |
| `text` | `video/src/script/ep*.ts` | 字幕，也是默认念法 | `等待 5 秒` |
| `tts` | 同一句的可选字段 | 只修改这句的配音念法 | `等待五秒` |
| `spokenText()` | `video/scripts/spoken-text.ts` | 全部句子的统一转换 | `×` → 乘 |
| 引擎写法表 | 按引擎另行配置，模板未提供 | 处理当前引擎的术语读音 | `AI` → `A I`，须试听验证 |

`spokenText()` 包含两部分：

- `readingText`：真人朗读时也会采用的转换，提词稿使用这一层。模板的规则包括去掉引号、展开乘号和范围符号。
- `pinPolyphones`：专门给 TTS 的多音字替换，字幕和真人提词稿保留原字。

## 多音字

模板使用同音字限制部分多音字的读法，例如：

```ts
export const pinPolyphones = (text: string) =>
  text
    .replace(/重(绘|抽|画|用)/g, '虫$1')
    .replace(/载(入|进)/g, '在$1');
```

完整规则在 `video/scripts/spoken-text.ts`。规则按词限制范围，换引擎后重新试听，不要默认同一替换始终有效。

模板替换时保持字数，提词稿因此能在原位置标注拼音。引擎支持发音控制时，也可以使用它自己的标音能力。

## 听写不能替代试听

自动听写可能按上下文把读错的字写成正确文本。文字一致，不代表声调和断句正确。

可以用不同的配音写法合成完整句子，做对照试听。最终确认由人耳完成，不只看听写结果。

## 数字与缩写

以下只演示字幕和念法如何分开，不表示某种写法适用于所有引擎：

- `5 秒` → `五秒`。
- `AI` → `A I`。
- `Model.2` → `Model 2`。
- `example.com` → `example 点 com`。

字幕与配音字数不同时，`captions.ts` 的 `alignBoundaries` 用编辑距离做文字对齐，再结合时间戳确定字幕块的起始帧。对应行为由 `captions.test.ts` 覆盖。

## 断句与字幕

配音停顿不自然时，先看句子本身是否容易歧义。调整语序或把长句拆开，字幕和口播一起改，再试听完整段落。

字幕用真实时间戳计时，尽量在标点处断句，过短的块与相邻块合并，引号里的内容不拆开。模板的最短字幕检查在 `pnpm delivery-check --timing-only` 中；生成时间戳后再运行。

## 术语写法表

引擎不支持指定发音时，按自己的术语准备几种输入写法，放进相同的完整句子试听。记录字幕原文、目标读音、候选写法与试听结论。

不要直接复制别的项目的品牌名、角色名或特殊读法。正确的写法取决于当前引擎、语言和语境。

## 音素检查

听写无法可靠区分术语时，可以另外增加音素检查。以下是扩展思路，模板没有提供完整的音素评分和自动重录工具：

1. 先由人确认目标读音，准备有授权的标准音。
2. 把待检查的词与标准音转换为音素，再比较对应范围。
3. 只计算目标词对齐范围内的音，避免把缺失或多出的音误当成相邻字。
4. 需要严格区分的音单独设规则，不能只依赖平均分。
5. 阈值和重试上限用自己的样本校准，低分片段进入试听或有限次重录。

目标设错时，评分再高也没用。读法由人定，工具负责筛出值得再听的片段。

## 片段拼接

把正确术语片段替换进完整句子时，需要处理切点、音高、音量、交叉淡化，以及长度变化后的时间戳。

即使技术上接好了，句首、句中和列举里的语调也可能不一样。先听完整句子，拼接明显时回到整句生成，不只听被替换的词。

## 检查清单

- [ ] 术语表里写明目标读音，并经过人工确认
- [ ] 多音字规则按词限制范围，避免误改其他语境
- [ ] 数字和符号的念法写入 `tts` 或统一转换
- [ ] 断句调整后重新试听，并同步字幕
- [ ] 生成时间戳后运行字幕与时间轴检查
- [ ] 成片完整试听，重点复查术语和补录部分
