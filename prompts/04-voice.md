# 配音和读音

以下为通用示例。候选声线、试听文本和目标读音按自己的项目填写。

## 调研

```text
请比较适合 <语言与用途> 的配音方案，先不要全量生成。
看长段听感、术语与多音字、跨句一致性、修改成本和时间戳支持。
核对授权、当前额度和限流，用我的脚本体量估算费用与时间。
本地方案还要考虑资源占用，别沿用其他机器的性能数据。
给出候选与待确认项，我确定后再做试听。
```

## 试听

```text
用 <试听文本> 比较候选声音，每个引擎先选一个声线。
同一句的音频并排放到试听页，统一响度，标出应该关注的读音或停顿。
短句选出候选后，再提供一段完整讲解，检查连贯性与语气。
```

## 批量生成

```text
选择 <引擎与声线> 后，先按确认的语气生成一个完整场景。
我试听通过再扩展，输出可复用的脚本、音频清单和生成记录。
文字、念法、语气或生成配置改变时，让相关缓存失效；其余结果复用。
支持失败重试与续跑，装入渲染工程前先确认负责人和最新状态。
```

## 校准读音

```text
请整理脚本中的术语、缩写和多音字，先让我确认目标读音。
对 <词> 试几种配音写法，放进同一句完整文本做试听对照。
字幕保持正确写法，确认后只更新配音念法。
自动听写与音素检查只负责筛选，最终结论以试听确认结果为准。
```

## 声音授权

```text
参考音与声线必须有对应使用授权。
需要原创声音时，用音色、语气、语速等声音特征描述，不使用真人或角色身份。
记录使用范围与需要保留的声明，公开发布前再次核对。
```
