# 交接和并行

以下是本地协作的通用示例。公开分享前，替换真实工作区、会话标识和文档链接。

## 更新交接

```text
请更新 HANDOFF.md，先保留旧版。
写清本轮进展、已确认要求、试过的方案、检查结果、后台任务和下一步。
区分已经确认的决定与尚未采纳的建议，不把建议写成既定要求。
涉及其他工作线的文件，标出当前负责人。
```

## 接续工作

```text
请把当前状态整理成一段可复制给新会话的说明。
列出先读的文件、任务目标、已完成且无需重复的工作、并行修改和下一步。
使用项目内相对路径；需要本地绝对路径时留在私有交接记录中。
说明哪些结论已验证，哪些仍需我确认。
```

## 分工

```text
这条工作线负责 <任务范围>，允许修改 <文件范围>。
先读最新 HANDOFF.md 和 COORDINATION.md，确认其他任务的状态。
正式渲染一次只跑一个，修改他人负责的文件前先协调。
对方暂时离线时，留下可追踪的协调记录，不覆盖已有改动。
```

## 汇报

```text
请说明已完成、正在处理、尚未完成和需要我决定的内容。
需要检查的结果用场景或句子 id 定位，并提供当前验证结果。
本地文件位置只写在私有工作记录里，公开摘要使用通用描述。
```
