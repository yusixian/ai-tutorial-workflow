# 发布

以下为通用示例，不包含原视频标题、封面角色或预告片提示词。

## 投稿资料

```text
请按最新时间轴生成简介和章节目录，格式适配 <发布平台>。
检查字数、时间码、链接、署名与合成内容声明。
不加入制作备注、账号信息、内部文档或本机路径。
```

## 标题

```text
给出几个能准确说明教程内容的标题，分别解释重点。
不要写未经证实的效果保证，也不要把当前时长固定写进标题。
确认标题与最终脚本一致后，再同步封面和简介。
```

## 封面

```text
请按 <展示比例> 设计封面，用 <已获授权的素材>。
主标题和主体在缩小后仍要看得清，不加入内部版本名或临时信息。
提供小样，确认后再导出不同尺寸。
```

## 资料包

```text
阅读用的图文说明整理为 PDF，需要复制或筛选的内容放进表格。
长文本另给纯文本文件，检查图片清晰度、文件体积和复制效果。
导出前核对素材来源，移除私人链接和未公开的项目数据。
```

## 预告片

```text
请从已确认的教程内容中选出适合预告的片段，先给一份简短方案。
使用已授权素材与音乐，动效采用自己的版式，不复制其他视频的成稿。
先做一个小样，我确认后再继续，检查文字可读性和音画节奏。
```
