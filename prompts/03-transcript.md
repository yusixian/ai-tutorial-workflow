# 逐字稿

以下提示词与反馈均为通用示例，编号和时间码仅演示格式。

## 建逐字稿

```text
请从当前台词与时间轴生成可编辑的逐字稿。
每句保留编号、时间码和稳定 id；每个场景标明对应画面组件。
加上成片截图，并区分字幕原文与配音念法。
我按编号反馈后，你应能定位到台词或画面，不用猜是哪一段。
```

## 飞书同步

```text
把逐字稿和截图同步到我的飞书文档，用于评论和改字。
推送新版前先拉取未处理的评论和文字差异，列给我确认。
区分在线修改与文档版本落后造成的差异，不自动把旧稿写回本地。
确认修改后再更新脚本、配音与画面，最后推送新版并记录处理结果。
```

## 修改记录

```text
请准备一张修改记录表，字段包括场景、句子 id、原文、问题类型、修改要求和处理结果。
改完后按当前时间轴更新定位信息，让我能复查。
写入前读取最新版，只修改负责的区域，不覆盖其他人的新反馈。
```

## 反馈示例

```text
settings-demo-02：增加操作前后的对比，配音确认后再更新画面。
设置面板场景：按钮提示遮住字幕，请调整位置并给一张静帧。
00:05：这里的停顿不自然，请先给两种改法让我选。
```
